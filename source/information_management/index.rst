Information Management
======================

**Information Management** is a core course covering how organizations collect, store, process, and secure data. It bridges raw computer hardware with business decision-making.

        Entity-Relationship Diagram (ERD) is a data modeling technique that graphically illustrates an information system's entities and the relationships between those entities. It's a conceptual and representational model fo data used to represent the entity framework infrastructure.

        A widely adopted standard for visualizing, specifying, constructing, and documenting the artifacts of software systems.

    .. grid-item-card:: Database Normalization
        :link: ./database_normalization
        :link-type: url

        An important process in relational database design aimed at organizing data to minimize redundancy, enhance data integrity, and improve database efficiency. It is a systematic process used in relational database design to organize data efficiently by dividing large, complex tables into smaller, related tables.

    .. grid-item-card:: Database Administration
        :link: ./db_administration
        :link-type: url

        Database administration focuses on the operational management of database systems so that they remain available, reliable, secure, and performant. Three core responsibilities are **concurrency ontrol**, **security management**, and **backup and recovery**. These functions direectly affect the quality, reliability, and safety of the data that supports organizational processes.

    .. grid-item-card:: Distributed Databases
        :link: ./distributed_db
        :link-type: url

        **Distributed databases** are colelctions of logically related data that are physically stored across multiple sites, servers, or geographical locations. Despite being distributed, they are intended to appear to users as a coherent system that supports consistent storage and retrieval of information.

    .. grid-item-card:: Patterns of Data Distribution
        :link: ./data_distribution
        :link-type: url

        In distributed database systems, **patterns of data distribution** determine how data is stored across multiple servers or locations. Appropriate choices influence reliability, scalability, performance, and security. Three common patterns are **replication**, **vertical partitioning**, and **horizontal partitioning**.
